# 项目销售管道重设计

## 目标

将现有"项目进度"页面从简单表格改造为专业的销售管道管理视图，支持从获客到售后的全流程追踪。

## 业务背景

向医院和代理商销售病案无纸化归档软件，销售流程：接触洽谈 → 投标 → 签约 → 实施 → 验收 → 售后。

## 设计

### 页面结构

1. **顶部工具栏** — 搜索框、阶段筛选、快速创建按钮
2. **销售漏斗统计** — 6阶段漏斗图，每阶段显示金额合计和项目数
3. **看板视图** — 6列看板，卡片可拖拽换阶段
4. **右侧详情面板** — 点击卡片滑出，不遮挡看板
5. **快速创建弹窗** — 极简表单（项目名+客户+金额+负责人）

### 卡片信息

每张卡片展示：项目名、客户名、预算金额、中标概率、竞争对手、负责人、预计签单日。超过7天未跟进标红色预警。

### 详情面板

Tab 切换：跟进记录（时间线）、投标信息编辑、实施阶段、任务列表。

### 数据库变更

- projects 表新增 `probability` (Integer, 中标概率 0-100)
- projects 表新增 `expected_sign_date` (Date, 预计签单日期)
- projects 表新增 `last_followup_at` (DateTime, 最后跟进时间)

### API 变更

- 项目列表 API 返回 customer_name（JOIN customers）
- 项目列表 API 新增筛选参数：manager, probability 范围
- 新增 GET /projects/stats/funnel 漏斗统计端点
